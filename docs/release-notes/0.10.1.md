# Assegai ORM 0.10.1 Release Notes

Assegai ORM 0.10.1 restores the caller-controlled sensitive-field read behavior that was unintentionally broken by the 0.9.5 security hardening and carried into 0.10.0.

## Highlights

- Sensitive properties remain excluded from reads by default.
- An explicitly supplied `exclude` list is authoritative again.
- Passing `exclude: []` restores the trusted-read escape hatch required by authentication and other internal workflows.
- The restored behavior applies consistently to repositories, `EntityManager::find()`, `EntityManager::findBy()`, and relation reads.

## Sensitive-field reads

The default find options continue to protect `password`, custom `PasswordColumn` properties, legacy columns mapped to the database column `password`, entity-protected properties, and manager-configured secure properties.

Applications that intentionally need a sensitive value can opt in for a specific trusted query:

```php
$result = $users->find([
    'where' => ['email' => $email],
    'exclude' => [],
]);

$user = $result->getData()[0] ?? null;
$authenticated = $user !== null
    && password_verify($plainPassword, $user->password);
```

Do not return or serialize the resulting credential value. Keep this override inside trusted application services and continue using the default exclusions for public responses.

Selective exclusion lists are also caller-controlled. For example, `exclude: ['email']` excludes `email`; the ORM no longer silently adds sensitive fields to an explicitly supplied override.

## Compatibility

No database or entity migration is required.

Applications using the established `exclude: []` authentication pattern can upgrade without changing that code. Applications that pass a custom non-default exclusion list should verify that the list names every field they intend to omit, because explicit lists are once again authoritative.

## Verification

- Default redaction for custom and legacy password mappings
- Explicit trusted reads through repositories, `find()`, and `findBy()`
- Manager-configured sensitive-property overrides
- Selective caller-controlled exclusions
- Relation-read exclusion handling
- Full PHPUnit and SQLite integration suites
