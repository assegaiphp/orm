# Assegai ORM 0.11.0 Release Notes

ORM 0.11.0 aligns the package with the coordinated AssegaiPHP 0.11 release line.
This release changes the Util dependency requirement and introduces no ORM runtime
or database schema changes.

## Compatibility

- PHP 8.4 or later remains required.
- `assegaiphp/util` now requires `~0.11.0`, allowing patches within the 0.11 line.
- Core and Console remain optional. Applications using those integrations should
  install their coordinated 0.11.x releases.
- `EntityInspector::getInstance()` and `TypeResolver::getInstance()` remain
  available throughout 0.x; their documented removal target remains 1.0.0.
- The opt-in entity hydration and caller-controlled read exclusions from 0.10.2
  remain available with the same behavior.

## Upgrade

After the coordinated packages are published, update ORM and Util together. In an
Assegai application, update the other installed framework modules to the 0.11 line
in the same dependency resolution. Patch versions may differ within that line.

Existing compatible Attributes 1.0.x and the coordinated RabbitMQ/Beanstalkd 1.2.x
adapter streams retain their established versioning. They do not change the
framework's 0.11 version.

No entity changes or database migrations are required for this alignment. Keep
existing read options, including `hydrate: true` and trusted `exclude: []`
overrides, unchanged.
