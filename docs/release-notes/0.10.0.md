# Assegai ORM 0.10.0 Release Notes

AssegaiPHP 0.10.0 release-line synchronization. This package contains no runtime behavior changes in this milestone; it is released to keep first-party framework packages aligned.

## Compatibility

- `assegaiphp/util` now targets `^0.10.0`.
- `EntityInspector::getInstance()` and `TypeResolver::getInstance()` remain available in 0.10.0.
- Their documented removal target is corrected from 0.10.0 to 1.0.0, preserving the promised 0.x compatibility window.

## Database sync roadmap

Entity-driven database sync is not part of this release. Its design remains in `docs/entity-driven-database-sync-plan.md`, and the Core roadmap treats it as a likely post-1.0 candidate without assigning it to 0.11.0.

## Upgrade

No ORM runtime or schema changes are required for this synchronization release. Continue replacing new singleton-accessor usage with direct construction or dependency injection before ORM 1.0.0.
